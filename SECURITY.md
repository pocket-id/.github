# Security Policy

## Supported Versions

Use the latest stable release of each Pocket ID project. Security updates are provided for the latest release. Read the release notes before upgrading between major versions.

## Reporting a Vulnerability

Thank you for taking the time to report a vulnerability. Please do not report vulnerabilities in public GitHub issues.

Open the affected repository's **Security and quality** tab and use **Report a vulnerability** to report it privately. If private reporting is unavailable there, report it through [Pocket ID's private vulnerability reporting form](https://github.com/pocket-id/pocket-id/security/advisories/new), specifying the affected repository.

See the [GitHub documentation on privately reporting a vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) for details.
